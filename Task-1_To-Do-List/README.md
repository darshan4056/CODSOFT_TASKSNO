Task 1 – To-Do List

Project Description

The To-Do List is a simple and responsive web application designed to help users organize and manage their daily tasks efficiently.

Features

- Add new tasks with validation.
- Edit existing tasks.
- Delete unwanted tasks.
- Mark tasks as completed or pending.
- Save tasks using Local Storage.
- Display completed and pending task counts.
- Search and filter tasks.
- Task categories and priority levels.
- Due dates.
- Dark mode support.

Technologies Used

- HTML
- CSS
- JavaScript
